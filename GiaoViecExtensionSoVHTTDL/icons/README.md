# Icons

Đặt các file icon vào thư mục này:

- `icon16.png` - 16x16 pixels (hiển thị trong menu extension)
- `icon48.png` - 48x48 pixels (hiển thị trong trang quản lý extension)
- `icon128.png` - 128x128 pixels (hiển thị trong Chrome Web Store)

## Tạo icons

Bạn có thể:
1. Sử dụng tool online như https://www.favicon-generator.org/
2. Tạo từ một hình ảnh có sẵn
3. Sử dụng icon có sẵn và resize về các kích thước yêu cầu

## Màu sắc đề xuất

- Màu chính: #007bff (màu xanh dương)
- Nền: Trong suốt hoặc màu trắng
